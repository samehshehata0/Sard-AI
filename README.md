# 📖 About

**سَرْد AI** هو منصة تعليمية عربية تعتمد على الذكاء الاصطناعي لمساعدة الطلاب المعلمين في إنتاج قصص رقمية تعليمية عالية الجودة دون الحاجة إلى مهارات تقنية متقدمة.

تركز المنصة على:

- تبسيط عملية تصميم القصص التعليمية.
- تقليل الوقت والجهد المبذول في الإنتاج.
- تحسين جودة المحتوى التعليمي.
- دعم الدافعية الأكاديمية.
- تقديم تجربة استخدام عربية بالكامل (RTL).
